# 666关英语闯关游戏系统设计方案

## 🎮 核心设计理念

将原有的"自由选游戏模式"改造为"RPG式闯关战斗系统"，玩家通过完成英语题目来攻击怪物，难度从3岁水平逐级提升至雅思8分水平。

---

## 📊 666关体系架构

### 关卡分布
- **6个世界**，每个世界111关（110普通关 + 1Boss关）
- **World 1**: 关卡 1-111（难度：3-4岁 → 小学1-2年级）
- **World 2**: 关卡 112-222（难度：小学2-3年级 → 小学4年级）  
- **World 3**: 关卡 223-333（难度：小学4年级 → 初中1年级）
- **World 4**: 关卡 334-444（难度：初中1年级 → 初中3年级）
- **World 5**: 关卡 445-555（难度：初中3年级 → 高中3年级）
- **World 6**: 关卡 556-666（难度：高中 → 雅思8分）

### Boss关设计（每111关一个）
- 关卡111, 222, 333, 444, 555, 666为Boss关
- Boss血量更高，需要连续答对多题才能击败
- 击败Boss后解锁新世界

---

## 🐉 怪物系统

### 怪物等级与血量
```
普通怪血量 = 关卡号 × 2 + 10
Boss血量 = 普通关血量 × 3
```

### 怪物类型（4大族群）
1. **单词怪** - 对应单词认知游戏
2. **听力怪** - 对应听力反应游戏  
3. **拼写怪** - 对应字母拼写游戏
4. **句子怪** - 对应简单句对游戏

### 高级怪物（World 4+新增）
5. **翻译怪** - 中英互译题型（新增加游戏模式）

---

## ⚔️ 战斗系统

### 玩家攻击力
- 基础攻击力 = 年龄加成 × 10 + 技能加成
- 答对题目 = 造成攻击伤害
- 连击加成：连续答对 × 5 额外伤害

### 技能系统（3个主动技能）
1. **提示** - 消耗20金币，排除一个错误选项
2. **护盾** - 消耗50金币，抵挡一次错误
3. **暴击** - 消耗30金币，下一题伤害翻倍

### 金币获取
- 击杀怪物获得金币 = 怪物血量 ÷ 3
- Boss关金币翻倍

## 🗺️ 世界地图系统

### 地图界面
- 显示当前世界进度
- 已解锁关卡用绿色标记
- Boss关用红色标识
- 未解锁关卡灰色显示

### 解锁规则
- 必须通关前一关才能解锁下一关
- 击败Boss才能进入下一世界
- 可以重玩已解锁关卡练习

## 🎯 难度算法

### 动态内容生成（无需手写666关配置）
```javascript
function generateLevel(levelNum) {
  const world = Math.ceil(levelNum / 111);
  const worldProgress = (levelNum - 1) % 111 + 1;
  
  // 难度计算
  const baseDifficulty = world; // 1-6
  const difficulty = baseDifficulty + Math.floor(worldProgress / 30);
  
  // 单词/句子筛选
  const eligibleWords = vocabulary.words.filter(w => 
    w.difficulty >= difficulty && w.difficulty <= difficulty + 1
  );
  
  // 怪物属性
  const isBoss = levelNum % 111 === 0;
  const monsterHP = levelNum * 2 + 10;
  
  return { difficulty, monsterHP, isBoss, ... };
}
```
